# Guga 探针主题

为 [Monitor](https://github.com/monitor-probe/monitor) 打造的高颜值极简服务器监控主题。

集成了纯色、透明与毛玻璃卡片风格、无级背景遮罩调节、必应每日壁纸直连、全球节点分布地图、全网实时吞吐波形、多路延迟连通性监控及大卡片 / 紧凑 / 列表多维视图。

---

## ✨ 特性亮点

- **三模卡片风格**：支持「纯色固色」、「透明直出」与「半透明毛玻璃」自由切换，提供 0% ~ 100% 无级背景遮罩深度与高斯模糊调节。
- **壁纸自由定制**：内置「必应每日壁纸」与「必应随机壁纸」一键切换，同时支持自定义 HTTP/HTTPS 高清壁纸直链。
- **全形态自适应视图**：
  - **大卡片模式 (Grid)**：触感胶囊滑块仪表，CPU / 内存 / 存储 / 流量四维同轴对齐，内置独立延迟监控走势。
  - **紧凑卡片模式 (Compact)**：微型仪表胶囊，双行紧凑底栏聚合实时网速、平延、月流量用量与总计。
  - **精简列表模式 (List)**：宽屏与移动端高密度排布，资源占用率、实时速率、网络平延与配额用量一目了然。
- **全球节点分布地图**：内置 Natural Earth 高性能离线 SVG 点阵地图，支持按国家聚合统计与集群状态标记。
- **全网实时吞吐波形**：轻量级动态 SVG 曲线，秒级反映全集群上行与下行带宽负载。
- **多路连通性监控**：自动汇总并计算多路网络延迟平均值（ping），带有色阶预警与波动折线图。
- **轻量与极致性能**：全站静态 SPA 零额外服务端依赖，关键图表按需异步懒加载，构建包体积仅约 360 KB。

## 🛠️ 本地开发

开发服务器可直接将 `/api` 与 WebSocket 代理至运行中的 Monitor Hub：

```bash
# 安装依赖
npm install

# 代理到远程或本地 Monitor Hub
MONITOR_HUB=https://hub.example.com npm run dev

# 启动开发服务器
npm run dev
```

### 质量校验与测试

```bash
# Oxlint 静态代码检查
npm run lint

# 单元测试（格式化与 API 数据管线验证）
npm test

# 生产环境编译构建
npm run build
```

## 📦 一键打包与发布

运行打包脚本：

```bash
npm run pack
```

命令将自动校验构建产物并在项目根目录生成符合规范的安装包：
- `theme.tar.gz`
- `expressive.tar.gz`

### 主题包目录规范结构

```text
<themes-dir>/expressive/
├── theme.json         # 主题配置与元信息清单
├── preview.png        # 控制面板主题预览图
└── dist/              # 编译静态产物
    └── index.html
```

## 🚀 安装与使用

1. **管理后台上传**：登录 Monitor 管理面板，进入「主题管理」页面，直接点击上传或将 `theme.tar.gz` 拖入即可完成安装。
2. **服务器手工放置**：解压出的文件直接置于 Monitor Hub 的 themes 目录（如 `/opt/monitor/data/themes/expressive/`）下。
3. **个性化偏好配置**：
   - 管理员可在管理后台「主题设置」中配置全站默认的壁纸、排版方式与顶部公告；
   - 访客亦可在前台右下角设置面板中自由调节本机的深浅模式、卡片风格、遮罩浓度与配色方案。
